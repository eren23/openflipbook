# Saved scene text edits

Scene text edits propose bounded changes to the existing authored geometry. They use the same saved World editor proposal and transactional Apply path as manual edits. A model response never directly replaces the scene.

The owner selects an object or the entire saved place, describes a change and explicitly approves the quoted reservation. `POST /api/world/:sessionId/places/:geoId/text-edits` with `action: "plan"` reserves one durable request. The worker freezes the saved revision, canonical definition, selected object IDs, boundary connections and available saved material hashes before submitting one model call. `action: "preview"` creates one proposal with the job's immutable proposal ID. Repeated preview and Apply requests reuse its saved canonical definition. No model call runs during review or Apply. If another part of the world changes after preview, the original Apply correctly rejects its stale context. The explicit `refresh-preview` action uses a new durable review ID and the same saved model response, after verifying that this place's revision, geometry, materials and connections still match. It never rebases changed geometry or submits another model call.

Supported operations are move, appearance and dimension patches, roof height, door dimensions and position, explicit removal, and typed component additions. Existing object, entity, floor, room and opening IDs remain stable. A selected building also scopes its bound furnishings; new additions in that scope must bind to its saved building and floor IDs. Whole-place additions reuse the existing structural building validator and deterministic identity namespace. Bounds, circulation, doorway reachability, connection approaches and changed exterior collisions must validate before a proposal becomes ready. New materials and meshes require their separate generation quotes.

The raw provider text and parsed result are persisted before deterministic validation. A storage failure during validation leaves a recoverable `validating` job. Invalid geometry retains the response and reservation without a repair call. A provider timeout or lost submission acknowledgement becomes `submission_unknown`; it is never automatically resubmitted. Cancellation releases an unsent scheduled reservation once. Discarding a submitted or ambiguous result retains its reservation because the call may still be billable. The browser retries a lost queue acknowledgement with the same request ID, original endpoint, revision, scope and quote.

Applied scene snapshots retain inert `edit_sources` receipts with the request and model identity, frozen input hash, canonical output hash, selected and changed IDs, reservation, timestamp and connection dependency. Archives preserve these receipts without restoring paid execution state or raw provider responses.

## Operator configuration

The feature remains disabled by default. Set `SCENE_EDIT_ENABLED=1` and an independently verified `SCENE_EDIT_RESERVATION_USD` greater than zero and at most 10 on the backend, alongside the shared token and configured text model. Web and worker use the existing generation worker process and advertise `scene_edits: true`. `SCENE_EDIT_DAILY_CAP_USD` defaults to 1; the shared daily and session caps also apply. A zero or invalid scene-edit daily cap disables new reservations. Existing requests remain visible when the backend or worker is unavailable.

## Geometry-derived map artwork

A source-free world can create map artwork from its saved geometry through the Map artwork editor. Its exterior plan camera is orthographic, looks straight down and contains the complete authored place and object heights. The camera, scene revisions, masks and geometry hashes provide exact registration. No source image node or manual landmark fit is invented. The camera and `purpose: "map"` survive archive and fork. Map generation and review use ordinary saved-view illustration jobs, including independent quote consent and owner acceptance. Refreshing a historical map keeps its saved camera while rebinding to the current canonical geometry.
